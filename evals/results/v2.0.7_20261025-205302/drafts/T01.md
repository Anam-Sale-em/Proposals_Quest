# T01: n8n build that matches a sample project; High-trust client

Your goal is to build an n8n workflow for your demo request forms. You need an automation that triggers on new responses from both Typeform forms, checks the Google Sheet for duplicate emails and skips them, adds a new row with name, email, company, form name and timestamp, posts a message to the #sales Slack channel with a link to the row, and emails if any step fails. First, I will configure the Typeform triggers for both demo request forms to feed data into the n8n workflow. Second, I will implement the duplicate check logic by querying the Google Sheet for existing email addresses to skip duplicates. Third, I will map the form fields including name, email, company, form name, and timestamp into a new Google Sheets row. I did nearly this for a lead intake client: manual entry dropped from about 2 hours a week to under 10 minutes. Which email node would you prefer for the failure notifications?
