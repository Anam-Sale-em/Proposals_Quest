# T02: HubSpot and PostgreSQL sync; no HubSpot project in the profile

Your goal is to build a two-way contact sync between HubSpot and a PostgreSQL users table. First, I will analyze your PostgreSQL users table schema and HubSpot contact properties to map fields and identify timestamps for the most-recent-update-wins conflict resolution rule. Next, I will develop the Python service to listen for new signups and push them to HubSpot within 5 minutes. Then, I will implement the reverse sync from HubSpot to PostgreSQL for lifecycle stage changes, add conflict logging to record every conflict, and package the service for your server with a short README for your developer.
