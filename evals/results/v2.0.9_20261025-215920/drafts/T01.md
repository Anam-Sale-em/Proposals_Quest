# T01: n8n build that matches a sample project; High-trust client

Your goal is to build an n8n workflow that processes Typeform responses, updates Google Sheets, and alerts Slack. First, I will configure Typeform triggers in n8n for both demo request forms to capture new submissions via webhooks. Next, I will implement a duplicate check by querying the Google Sheet for an existing row with the same email address to skip duplicate entries. Then, I will add a new row to the Google Sheet containing name, email, company, form name, and timestamp for non-duplicate entries, post a short notification message to the #sales Slack channel with a link to the newly created spreadsheet row, and set up error handling and notification logic to email the team if any step in the workflow fails. I did nearly this: automated lead intake using n8n webhooks, Google Sheets API, and Slack API to eliminate manual data entry. Lead entry dropped from about 2 hours a week to under 10 minutes. What email service or node would you prefer to use for the failure notification emails?
